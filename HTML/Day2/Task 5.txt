Heading

Italic Text

and explain whether each element is:

Block Level
Inline

* Bold Text (<b>), Italic Text (<i>), Highlighted Text (<mark>), are formatting tags because Inline (Stays inside the text flow line) 
* Button (<button>, Input Field (<input>, Dropdown (<select>), Textarea (<textarea>) are interactive tags because it is customizable and can be accessed by the user.
