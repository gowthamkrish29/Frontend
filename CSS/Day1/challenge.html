CSS Core Concepts



Inline CSS

Inline CSS is used to apply unique style rules directly inside a single HTML element using the style attribute.



Internal CSS

Internal CSS embeds style rules within a style tag placed inside the head section of an HTML document.



Selectors

Selectors target specific HTML tags, classes, or IDs to determine which elements receive the style definitions.



Properties

Properties are the specific stylistic attributes you want to change, such as text alignment, width, or height.



Values

Values are the exact settings assigned to properties, like specific numbers, pixel dimensions, or color names.
